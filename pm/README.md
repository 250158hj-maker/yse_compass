## なぜ `docs/` と分けるのか

`docs/` は **設計の正典**（何を作るか・なぜそう決めたか）。ここは **進め方の正典**（いつ・誰が・どの順で）。

**混ぜると、設計を書く人以外がこのディレクトリを読まなくなる。** `docs/open-questions.md` の記号 `P-n`（プロジェクト運営の未決）が、このディレクトリと対になっている。

**Notion ではなくリポジトリに置く理由は、2026-08-30 の `docs/` 移管とまったく同じ。**
MCP は水戸しか使えないため、**蒲山・鈴木の Claude Code は Notion を読めない**（`../docs/decisions.md` 2026-08-30 の行）。スケジュールを Notion に置く限り、機械に届ける手段は手作業の複製しかない。
